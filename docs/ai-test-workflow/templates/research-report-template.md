# Research Report Template

이 문서는 Researcher 에이전트가 테스트 현황을 조사한 뒤 작성할 결과 양식이다.

Researcher는 파일을 수정하지 않고 조사 결과만 기록한다.

## 실행 정보

```text
실행 일시:
사용 모델:
에이전트 역할: Researcher
사용 프롬프트:
참조 문서:
조사 범위:
```
